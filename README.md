# Still

A responsive landing page built with HTML, CSS, and a small vanilla JavaScript enhancement for accessible escape details. No build step or package installation is required.

## Run locally

From this directory, run `python3 -m http.server 8000 --bind 0.0.0.0`, then open port 8000 in a browser. You can also open `index.html` directly.

The page includes responsive navigation, anchor links, two escape detail dialogs, keyboard focus styles, and reduced-motion support. The contact link uses `hello@example.com` as a placeholder; replace it with your address before publishing. Still is a fictional brand.

Photography is stored locally from the [Start Bootstrap Grayscale](https://github.com/StartBootstrap/startbootstrap-grayscale) template (MIT license), originally sourced from Unsplash. Fonts are DM Sans and Libre Caslon Display from Google Fonts, self-hosted with system fallbacks. License notices are included in `assets/`. The page makes no requests to external services.
